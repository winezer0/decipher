# decipher

decipher 是一个基于 Go 语言编写的高性能本地哈希解密工具。它利用预计算（彩虹表原理）的方式，通过构建本地哈希缓存库来实现快速的哈希查找与解密。支持多种常见的哈希算法，并内置了常用的弱口令字典。

## 1. 功能介绍

*   **高性能解密**: 利用 Go 语言的并发特性，快速进行哈希计算和匹配。
*   **多算法支持**: 内置 30+ 种哈希算法，涵盖 MD5, SHA 系列, MySQL, NTLM, MSSQL 等。
*   **预计算缓存**: 支持将自定义字典和内置字典预先计算为哈希表（Cache），极大提升后续的解密速度。
*   **动态哈希算法**: 支持运行时动态验证哈希值，无需预计算所有可能的哈希组合。
*   **Salt支持**: 支持带 Salt 的哈希计算和解密，可灵活配置 Salt 组合模式。
*   **内置字典**: 集成 Top100 等常用弱口令，开箱即用。
*   **结果导出**: 支持将解密结果导出为 CSV 文件。
*   **算法猜测**: 支持通过hash和salt进行算法猜测。

## 2. 程序运行逻辑与解密原理

decipher 的核心原理是**基于预计算的字典攻击（Pre-computed Dictionary Attack）**。

### 运行逻辑

1.  **缓存生成阶段 (Cache Generation)**:  
   *   用户提供明文字典（或使用内置字典）和可选的 Salt。
   *   程序遍历所有支持（或指定）的哈希算法，计算 `Hash = Algorithm(Plaintext + Salt)`。
   *   将计算结果以 `Hash:Salt:Plaintext` 的格式存储在本地缓存目录中（默认位于用户目录下的 `.decipher`）。
   *   这一步通常只需执行一次，生成的缓存越丰富，解密成功率越高。

2.  **解密匹配阶段 (Crack/Match)**:  
   *   用户输入待解密的哈希值（Target）。
   *   程序首先检查成功缓存，快速返回已破解的哈希结果。
   *   对于未破解的哈希，程序分为两个阶段进行破解：
     *   **静态破解阶段**：使用预计算的哈希缓存进行快速匹配，适用于常见的哈希算法和组合。
     *   **动态破解阶段**：对静态破解失败的哈希，使用动态哈希算法进行实时验证，无需预计算所有可能的组合。
   *   解密成功后，结果会被保存到成功缓存中，以便后续快速查询。

3.  **加密模式 (Encryption Mode)**:  
   *   用户可以输入明文和可选的 Salt，程序会使用指定的算法计算哈希值。
   *   支持批量加密多个明文，并可指定多种算法同时计算。

### 动态哈希算法解析

动态哈希算法是 decipher 的一个重要特性，主要用于处理那些无法通过预计算缓存进行破解的哈希算法。动态算法的特点是：相同的明文和salt，每次计算得到的hash值都不同（如bcrypt）。

#### 工作原理

1.  **触发条件**：
   *   动态破解只在静态算法解密失败后启用
   *   只有当用户指定了动态算法（如bcrypt）时才会执行
   *   静态算法解密失败的目标会进入动态破解阶段

2.  **实时验证**：
   *   程序会加载用户指定的字典文件或使用内置字典
   *   对字典中的每个明文字符串，使用动态算法的 `Verify` 方法进行实时验证
   *   不需要预计算所有可能的哈希值，直接验证hash是否匹配明文

3.  **并发处理**：
   *   程序使用多线程并发处理字典中的明文字符串
   *   提高破解效率，加快验证速度

4.  **结果缓存**：
   *   动态破解的结果会被缓存到 `.hashcache` 目录中
   *   下次遇到相同的哈希值时，会直接从缓存中获取结果，提高效率

5.  **进度反馈**：
   *   程序会定期输出处理进度，显示已处理的字典行数和耗时

#### 支持的动态算法

动态算法主要包括那些具有以下特点的哈希算法：
*   **bcrypt**: 基于Blowfish加密算法的密码哈希函数，每次计算结果都不同
*   **其他动态算法**: 任何相同的明文和salt每次计算得到不同hash值的算法

#### 动态算法与静态算法的区别

1.  **静态算法**（如MD5、SHA系列）：
   *   相同的明文和salt，每次计算得到的hash值相同
   *   可以预计算所有可能的hash值并存储到缓存中
   *   解密时直接查询缓存，速度极快

2.  **动态算法**（如bcrypt）：
   *   相同的明文和salt，每次计算得到的hash值都不同
   *   无法预计算，必须实时验证
   *   解密时通过 `Verify` 方法逐个验证明文是否匹配

#### 动态破解的使用场景

1.  **bcrypt等动态算法**：当需要破解bcrypt等动态算法生成的哈希时
2.  **静态算法破解失败**：当静态算法无法破解某些哈希时，会自动尝试动态算法
3.  **指定动态算法**：用户明确指定使用动态算法进行破解时

### 解密原理图解

```text
[待解密 Hash]
       |
       v
[检查成功缓存] --> [命中] --> [返回解密结果]
       |
       v
[静态破解阶段]
       |
       +--> [预计算缓存 (Hash:Salt:Plain)] --> [匹配] --> [成功] --> [保存到成功缓存] --> [返回解密结果]
       |
       v
[失败]
       |
       v
[动态破解阶段] (仅在静态破解失败且指定了动态算法时执行)
       |
       +--> [字典文件/内置字典] --> [并发验证] --> [Verify方法] --> [成功] --> [保存到动态缓存] --> [返回解密结果]
       |
       v
[失败] --> [无法解密]
```

## 3. 命令行参数说明

使用 `./decipher -h` 可查看帮助信息。以下是参数的中文详细介绍：

### 基础输入输出
*   `-i, --inputs`: 输入要解密的哈希值，或包含哈希值的文件路径（每行一个）。
*   `-o, --output`: 指定解密结果导出的 CSV 文件路径。

### 缓存构建与字典管理
*   `-d, --dec-dicts`: 指定自定义字典文件路径或直接输入字典字符串，用于生成明文字典的hash缓存。
*   `-s, --dec-salts`: 指定 Salt 字符串或包含 Salt 的文件路径，用于生成明文字典+salt字典的hash缓存。
*   `-w, --workers`: 指定生成缓存时的并发工作线程数（默认为 0，自动适配）。
*   `-R, --rec`: 清空缓存目录下的所有文件，使用后需要重新生成缓存。
*   `-D, --dec`: 对hash预计算缓存文件进行去重整理。

### 算法控制
*   `-a, --algos`: 指定使用的哈希算法（例如 `md5`, `bcrypt`）。如果不指定，默认使用所有可用算法解密。
*   `-L, --list`: 列出当前支持的所有哈希算法。

**注意**：算法分为静态算法和动态算法两种类型：
*   **静态算法**（如MD5、SHA系列）：可以预计算缓存，解密速度快
*   **动态算法**（如bcrypt）：无法预计算，只能实时验证，只在静态算法解密失败后执行

### 加密模式
*   `--et, --encrypt-text`: 输入要加密的明文，或包含明文的文件路径（每行一个）。
*   `--es, --encrypt-salt`: 输入加密时使用的 Salt，或包含 Salt 的文件路径（每行一个）。

### 其他选项
*   `--data-dir`: 指定工具的数据存储目录（默认 `~/.decipher`）。
*   `--ll`: 设置日志级别 (debug, info, warn, error)，默认 `info`。
*   `--lf`: 指定日志输出文件路径。
*   `--lcf`: 控制台日志格式，可选 T(时间)/L(级别)/C(调用处)/F(函数)/M(消息)，默认 `LM`。
*   `-v, --version`: 显示程序版本信息并退出。

## 4. 使用示例

### 4.1 初始化缓存（首次使用推荐）
使用内置字典生成缓存：
```bash
./decipher -d
```

### 4.2 添加自定义字典
将 `my_passwords.txt` 中的密码，并使用salt=666 来进行hash预计算并加入缓存：
```bash
./decipher -d ./my_passwords.txt -s 666
```

### 4.3 单个哈希解密
```bash
./decipher -i e10adc3949ba59abbe56e057f20f883e
```

### 4.4 批量解密
从 `hashes.txt` 读取哈希列表进行解密，并将结果保存到 `result.csv`：
```bash
./decipher -i ./hashes.txt -o ./result.csv
```

### 4.5 指定算法解密
只使用 MD5 算法进行解密：
```bash
./decipher -i e10adc3949ba59abbe56e057f20f883e -a md5
```

### 4.6 使用动态算法解密
使用 bcrypt 动态算法进行解密（注意：动态算法只在静态算法解密失败后执行）：
```bash
./decipher -i <bcrypt_hash> -a bcrypt -d ./custom_dict.txt
```

同时使用静态和动态算法进行解密：
```bash
./decipher -i <hash> -a md5,bcrypt -d ./custom_dict.txt
```

### 4.7 加密模式
使用 MD5 算法加密明文 "123456"：
```bash
./decipher --et 123456 -a md5
```

使用多个算法加密明文 "password" 并添加 Salt "salt123"：
```bash
./decipher --et password --es salt123 -a md5,sha1,sha256
```

### 4.8 动态破解示例
使用自定义字典和动态算法进行解密：
```bash
./decipher -i <bcrypt_hash> -a bcrypt -d ./custom_dict.txt
```

注意：动态破解只在以下情况下执行：
1. 静态算法解密失败后
2. 用户明确指定了动态算法（如bcrypt）
3. 程序会先尝试静态算法，失败后才使用动态算法
